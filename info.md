# PC Control Card

A Lovelace custom card for controlling a PC from Home Assistant — **turn on, sleep, shutdown** — with live CPU / RAM / GPU metrics.

- Two variants: compact `tile` and full `feature` with metric bars
- Per-action 2-tap confirmation (`confirm_shutdown`, `confirm_sleep`)
- Follows your active HA theme (light & dark) via standard CSS variables
- Single JS file, no build step

See the [README](README.md) for full install and configuration details.
